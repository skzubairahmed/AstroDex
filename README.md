# AstroDex
A database for all kinds of satellites, asteroids and exoplanets.

## Description:-
AstroDex is a webapp where you can find all kinds of data about exoplanets, satellites, and near-earth satellites.
You can also track various satellites.
[I am also thinking of adding an AI feature whihc could give you info about any near-earth object you want.]

## Pages:- 
As of now the webapp consists of 6 main pages :-
1. Home - Contains a "Bookmarked Objects" tab, Live system metrics about number of objects being tracked and some other information, a preview of the NASA Astronomy Photo Of the Day(APOD) and a Real Time ticker showing asteroids making close contact with Earth.

2. Satellites - Contains a table of all the tracked satellites. You can filter through and search through the table to find your desired satellite(s). You can also click on a satellite to get more information about it.

3. Exoplanets - Contains a table of all discovered exoplanets, both confirmed and suspected. You can filter through and search through the table to find your desired exoplanet(s). You can also click on an exoplanet to get more information about it.

4. Asteroids - Contains a table of all known and tracked asteroids. You can filter through and search through the table to find your desired asteroid(s). You can also click on an exoplanet to get more information about it.

5. Tracker - Contains a list of certain satellites and/or other near-earth objects which you can track live over the world-map

6. NASA APOD - Contains the NASA Astronomy Picture Of the Day(APOD) and information about it.
